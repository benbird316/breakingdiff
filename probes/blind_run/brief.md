# Blind-run brief: comparing two materials

You have never seen the breakingdiff project and do not know what it does. Your only
entry point for learning it:

    read ./SKILL.md

Your working directory is the repository root — the directory that holds `SKILL.md`
and `examples/`. Every relative path below resolves against it.

Once you have read that, analyse these two materials:

- Material A: `./examples/data/eslintrc-2016-08.json`
- Material B: `./examples/data/eslintrc-2019-03.json`

Task: determine the relationship between Material A and Material B, and give your
conclusion. Get the tool actually running, and report both the conclusion and the
process.

The report must contain three parts:

1. Ramp-up: which files you read, how far you got in each, and how you decided what to
   do next.
2. Tool reality: the commands or calls you actually executed, and the tool's actual
   output — quote the key readouts verbatim, do not paraphrase them.
3. Final conclusion: what the relationship between Material A and Material B is, and
   which of the tool's readouts it rests on.

Honest-answer boundaries:

- Where `SKILL.md` points at something you cannot understand or cannot reach, record
  it as it is. Do not invent.
- When the tool will not start or errors out, paste the error text in full — an error
  is a valid result, not a failure.
- Do not fabricate features, parameters or output shapes you have not seen.

## Readable and forbidden

Readable: `SKILL.md`, the two materials above, the files `SKILL.md` explicitly tells
you to read, and the tool's own scripts.

Forbidden: any organizer material beyond this brief (the grading table, the run
notes, the changelog, and any local development memory directory). If you find you
have already read forbidden content, stop immediately and say so honestly; the result
is treated as contaminated.
